Age of Abundance v4.0 — Brothers Edition
========================================

Web
---
The files in this folder are the complete offline game. Upload them to
Netlify (or any static host) with index.html at the root. No build
command is needed. Export a save before moving domains.

Native wrappers
---------------
The Capacitor  project lives in /workspace/game-v4-app (appId
com.uygartuna.ageofabundance). It bundles this folder so the game
runs offline on Android and iOS. Debug APK and store steps are
documented there.

The earlier "Full Project ZIP" is not required; v4 replaces it.
